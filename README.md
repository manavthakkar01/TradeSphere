# 📈 TradeSphere

> A production-inspired full-stack stock trading and portfolio management platform built with the MERN stack.

TradeSphere provides an intuitive trading experience with portfolio management, holdings tracking, order management, and interactive dashboards inspired by modern fintech platforms.

---

## 🚀 Features

- 📊 Interactive Trading Dashboard
- 💼 Portfolio Management
- 📈 Holdings & Positions Tracking
- 🛒 Buy & Sell Order Management
- 📉 Portfolio Analytics & Charts
- 📡 RESTful API Integration
- ⚡ Fast & Responsive User Interface
- 📱 Modern Fintech-Inspired Design

## ⚙ Installation

### Clone Repository

```bash
git clone https://github.com/manavthakkar01/TradeSphere.git
```

### Navigate to Project

```bash
cd TradeSphere
```

### Install Backend

```bash
cd backend
npm install
```

### Install Dashboard

```bash
cd ../dashboard
npm install
```

### Install Frontend

```bash
cd ../frontend
npm install
```

---

## ▶ Running the Project

### Backend

```bash
cd backend
npm start
```

### Dashboard

```bash
cd dashboard
npm start
```

### Frontend

```bash
cd frontend
npm start
```
